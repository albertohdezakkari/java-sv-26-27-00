# Misión 03 · Rescate · Prueba técnica

Entrega ficticia para comprobar el formulario y la corrección. No corresponde a ningún alumno real.

El programa construye e imprime la estación: un tablero de 10 × 10 con el robot, la meta, cinco obstáculos y una batería en posiciones libres aleatorias. El movimiento y las vidas están pendientes.

Requiere JDK 17. Desde esta carpeta:

```sh
javac -encoding UTF-8 src/Main.java
java -cp src Main
```

Al ejecutarlo se muestran diez filas con diez símbolos. Cada ejecución puede generar posiciones distintas para los obstáculos y la batería.
