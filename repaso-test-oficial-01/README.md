# Repaso tipo test oficial 01

Actividad formativa con las 15 preguntas tipo test del examen de repaso Java y sus cuatro opciones originales. Hay 90 segundos para responder cada pregunta. Al elegir una opción, queda bloqueada y se muestra la corrección; la siguiente pregunta solo se carga al pulsar «Siguiente». Se pueden revisar preguntas anteriores en modo solo lectura. El orden se aleatoriza.

La selección de cuenta y las respuestas se guardan únicamente en el navegador; no hay autenticación ni envío de resultados al registro docente.
