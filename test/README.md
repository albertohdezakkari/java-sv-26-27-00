# Test Java · Del código al tablero

Actividad independiente: 20 preguntas de lectura de código, con 40 segundos por pregunta y selección del alumno antes de empezar.

[Abrir test](https://albertohdezakkari.github.io/java-sv-26-27-00/test/).

Cada acierto suma 0,5 puntos sobre 10. Los errores no restan. Al finalizar, el servicio del profesor calcula la nota y registra el resultado y las respuestas. La pantalla confirma cuándo se ha guardado; si la conexión falla, conserva el intento y permite comprobar el registro sin duplicarlo.

El progreso se conserva en el navegador. La selección del nombre no autentica al alumno.
