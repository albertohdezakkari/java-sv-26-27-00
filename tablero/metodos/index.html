Tu tablero, por métodos

Aprende a escribir y llamar a un método con ejemplos cortos. Después aplica lo aprendido al juego que ya hiciste.

¿Qué entra al método? ¿Qué sale?

En Java, ambos son métodos. Los declaras una vez y puedes llamarlos con datos distintos.

Antes de avanzar. Abre «Archivo entero». Localiza las dos llamadas a sumar y predice qué líneas escribirá mostrarTotal. Comprueba que los dos resultados son Total: 7 y Total: 12.

Lee una declaración pieza a pieza

Dentro de la clase Main, escribe los métodos después de la llave que cierra main y antes de la última llave de la clase. La llamada se escribe dentro de main o de otro método.

static
El método pertenece a la clase. Aquí puedes llamarlo directamente desde main, que también es static.
int delante del nombre
Tipo de retorno. La llamada produce un entero. Para una acción sin valor de retorno, escribe void.
sumar y (int a, int b)
Nombre y lista de parámetros. Cada parámetro lleva su tipo y su nombre. Si el método tiene cero parámetros, escribe (), como en la declaración static void mostrarInicio() y la llamada mostrarInicio();.
{ return a + b; }
Cuerpo. Las llaves delimitan las instrucciones. return evalúa la suma, entrega el valor y termina la llamada.

La firma identifica el método

La firma de este ejemplo es sumar(int, int). En estos métodos, la forman el nombre y los tipos de sus parámetros en orden. El tipo de retorno, static y los nombres a y b quedan fuera de la firma.

sumar(int) y sumar(int, int) pueden coexistir porque tienen firmas distintas. Cambiar solo int por double delante de sumar produce dos declaraciones con la misma firma.

Antes de avanzar. Escribe la firma de mostrarTotal y la de main. Comprueba que quedan mostrarTotal(int) y main(String[]).

Sigue la llamada y el regreso a main

Usa «Siguiente paso» para seguir la primera llamada de cada método. Fíjate en cuándo se guarda el valor y cuándo aparece texto en la consola.

Un return valor; termina la llamada en ese punto. Cada camino que completa un método con resultado debe llegar a un return con un valor compatible. Si un if solo devuelve un valor cuando su condición es verdadera, comprueba también qué devuelve cuando es falsa. Un método void vuelve al llegar a la última llave o al ejecutar return;.

Qué entra, qué sale y qué cambia

Entrada · parámetros y argumentos
int a y int b son parámetros de la declaración. 4 y 3 son argumentos de sumar(4, 3). Java asigna los argumentos por posición, con tipos compatibles. En restar(8, 3), invertir los argumentos cambia el resultado de 5 a −5. Un argumento también puede ser una variable o una expresión.
Salida · valor de retorno
La salida de sumar(4, 3) es 7. int resultado = sumar(4, 3); guarda ese valor. System.out.println(sumar(4, 3)); lo muestra directamente. En Java, el resultado explícito sale por return; la lista de parámetros recibe los datos de entrada.
Efecto · consola o cambios en un objeto
mostrarTotal(7) escribe en consola. Un método void también puede modificar una casilla de una matriz que recibe. La escritura y la modificación son efectos de la llamada.

Java pasa los argumentos por valor. Con int, el parámetro recibe una copia del número. Con una matriz, recibe una copia de la referencia a la misma matriz: puedes modificar una casilla y ver el cambio desde main. Los parámetros y las variables locales pertenecen a su método.

Antes de avanzar. Predice qué valores imprimirá el ejemplo completo. Comprueba que salen 4 y P. Explica cómo puede cambiar la casilla con un método void.

Localiza tres errores al leer código

  • sumar(4) proporciona un solo argumento. La declaración del ejemplo pide dos.
  • int x = mostrarTotal(7); intenta guardar el resultado de una llamada void. Escribe mostrarTotal(7); como instrucción.
  • Un método int que solo contiene System.out.println(a + b); carece del retorno requerido. Para devolver la suma, escribe return a + b;.

Abre tu proyecto

En IntelliJ, abre la misma carpeta del juego y luego src/Main.java. Desde la carpeta del proyecto, usa Git Bash en Windows o Terminal en macOS para confirmar dónde estás.

pwd
test -f src/Main.java && ls src/Main.java

Si tienes el JDK disponible en la terminal y tu clase Main está directamente en src sin declaración package, puedes compilar y ejecutar desde la carpeta del proyecto con los mismos comandos en Git Bash y macOS. La carpeta temporal guarda los archivos compilados.

compilacion=$(mktemp -d) &&
test -d "$compilacion" &&
javac -d "$compilacion" src/Main.java &&
java -cp "$compilacion" Main

Devuelve el número de casillas libres

Añade contarLibres al lado de mostrarTablero. Después de colocar todas las piezas y antes de pedir una tecla, llama al método y guarda su resultado en int libres.

Empieza con un contador a cero, súmale uno por cada '*' y escribe return después de recorrer todas las filas. En main puedes imprimir libres o usarlo en otra comprobación.

Antes de avanzar. Predice cuántas casillas libres hay en el ejemplo de 4 × 4 y comprueba que imprime Casillas libres: 13.
