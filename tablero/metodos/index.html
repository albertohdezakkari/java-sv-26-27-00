Tu tablero, por métodos

Abre el juego que ya hiciste. Vas a extraer tareas de main para mostrar el tablero, contar casillas libres y decidir si puedes mover al jugador.

¿Qué le pides a cada método?

En Java, los tres ejemplos son métodos. En clase llamarás procedimiento al método con void y función al método que devuelve un dato con return.

void mostrarTablero(char[][] matriz)
Muestra las filas en consola.
int contarLibres(char[][] matriz)
Devuelve cuántas casillas contienen '*'.
boolean esCasillaLibre(char[][] matriz, int fila, int columna)
Devuelve true o false para una posición.

int fila es un parámetro de la declaración. En esCasillaLibre(matriz, 0, 1), el argumento 0 corresponde a fila y 1 a columna. Escribe estos métodos como static para llamarlos desde tu main.

Abre tu proyecto

En IntelliJ, abre la misma carpeta del juego y luego src/Main.java. Desde la carpeta del proyecto, usa Git Bash en Windows o Terminal en macOS para confirmar dónde estás.

pwd
test -f src/Main.java && ls src/Main.java

Si tienes el JDK disponible en la terminal y tu clase Main está directamente en src sin declaración package, puedes compilar y ejecutar desde la carpeta del proyecto con los mismos comandos en Git Bash y macOS. La carpeta temporal guarda los archivos compilados.

compilacion=$(mktemp -d) &&
test -d "$compilacion" &&
javac -d "$compilacion" src/Main.java &&
java -cp "$compilacion" Main

Antes de avanzar. Comprueba que aparece src/Main.java. Ejecuta tu juego y localiza en main los bucles que muestran la matriz.

Muestra el tablero con un procedimiento

Mueve los bucles de impresión a mostrarTablero. Escribe el método dentro de la clase Main, después de la llave que cierra main. En cada lugar donde imprimías la matriz, escribe mostrarTablero(matriz);.

print escribe cada símbolo en la misma línea. println() pasa a la línea siguiente cuando termina la fila. El tipo void indica que la llamada termina sin devolver un valor.

Antes de avanzar. Ejecuta el juego. En los mismos puntos de antes debes ver las filas completas. Busca las llamadas en main y comprueba que el bucle de impresión está escrito una sola vez.

Devuelve el número de casillas libres

Añade contarLibres al lado de mostrarTablero. Después de colocar todas las piezas y antes de pedir una tecla, llama al método y guarda su resultado en int libres.

Empieza con un contador a cero, súmale uno por cada '*' y escribe return después de recorrer todas las filas. En main puedes imprimir libres o usarlo en otra comprobación.

Antes de avanzar. Predice cuántas casillas libres hay en el ejemplo de 4 × 4 y comprueba que imprime Casillas libres: 13. En tu juego compara la salida con el número de casillas de tu matriz menos las ocupadas que realmente ves. Cambia temporalmente una casilla libre por un obstáculo y comprueba que el recuento baja exactamente uno. Revierte ese cambio de prueba.

Pregunta si una posición está libre

Añade esCasillaLibre. Primero comprueba si la fila existe. Después comprueba la columna de esa fila. Solo entonces lee el símbolo. Así puedes consultar coordenadas negativas o demasiado grandes y recibir false.

Usa el resultado para mover a tu jugador

Empieza con la tecla D. Calcula la columna de destino como la actual más uno. Usa esCasillaLibre dentro del if para decidir si puedes mover al jugador.

  1. Si está libre, borra la casilla de origen con '*', actualiza la columna y coloca el símbolo del jugador en el destino.
  2. Si está ocupada o fuera del tablero, conserva la posición original.
  3. Llama a mostrarTablero después del intento. Prueba primero el movimiento a la derecha. Luego adapta la idea a las demás teclas que maneje tu juego.
